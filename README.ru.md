# Elysium Analyzer Bot

Аналайзер для Elysium по образцу NEAR-аналайзера (@nearai_agent): канал всех деплоев мемпадов, сканер токенов, алерты MC/дипов в топиках группы, коллеры с PnL-карточками.

## Что умеет

| Функция | Как работает |
|---|---|
| 🚀 **Канал деплоев** | Каждую секунду читает mint-логи (Transfer from 0x0) новых блоков. Новый контракт → ждёт пул и по площадке определяет мемпад: **Kleos, ElysPump, Boxa, ELYXA, Obol, Montra, Stockium**. Пост: картинка, имя, тикер, описание и соцсети (достаются прямо из транзакции запуска), supply, MC, кошелёк дэва, его баланс HYPE, % supply у дэва, прошлые деплои дэва и лучший ATH среди них |
| 🔎 **Сканер** | Вставь `0x…` или ссылку Kleos / ElysPump / Stockium: свечной график 15m, цена, MC, ATH, ликвидность, объём и сделки (если токен есть на DexScreener), изменение 1H/6H/24H, мемпад, дэв и его деплои, холдеры и топ-10. Кнопки: DexScreener, страница мемпада, холдеры в эксплорере. График берётся с GeckoTerminal, а пока Elysium там нет — из цен, которые бот сам пишет каждую минуту. Холдеры — из API эксплорера, иначе бот считает их сам по Transfer-логам токена |
| 📈 **Алерты в топиках** | MC $10K / $20K / $30K / $50K / $100K и дипы −15% за час для токенов с мемпадов |
| 🎯 **Коллеры** | Первый, кто кинул контракт в группу, получает колл; 📊 PnL — карточка с персонажами; /callers — топ |
| 🛒 **Кнопки** | ⚡ Buy on Degen bot (сразу открывает карточку токена) и 🔵 Buy on Based с рефкой `r_Ramram` |

Цены и MC считаются on-chain через тот же `dex.py`, что и в Degen bot, — никаких платных API.

## Установка на сервер

```bash
cd /root && git clone https://github.com/LoveTon-crypto/elysium-analyzer-bot.git
cd elysium-analyzer-bot && bash deploy.sh      # создаст .env
nano .env                                      # BOT_TOKEN нового бота, DEGEN_REF (если есть)
bash deploy.sh
```
Обновление потом: `elys-analyzer-update`. Логи: `journalctl -u elys-analyzer -f`.

## Первый запуск

1. Напиши боту `/start` — первый, кто это сделает, становится админом.
2. Создай канал, добавь бота админом, в личке бота: `/setdeploys @канал`.
3. Для алертов: форум-группа, бот админ, в нужном топике `/settopic 10k`, `/settopic dip` и т.д.
4. `/deploys` — статус ленты, `/deploytest 0x…` — превью поста в личку, `/pads` — контракты запуска, которые бот не узнал (их можно добавить в `PAD_FACTORIES`).

`BACKFILL_BLOCKS=200000` в `.env` — один раз при старте подтянет старые деплои, чтобы у дэвов сразу считались прошлые запуски.
